# Japan TV Only

This is a simplified version of the IPTV project containing only its Japan channel playlist.

## Files
- `japan.m3u8` — Japanese TV channel playlist
- `playlist.m3u8` — same playlist, provided as a convenient default filename

## How to use
Open/import `japan.m3u8` in an IPTV player that supports M3U/M3U8 playlists (for example, VLC).

If you host this repository on GitHub, use the **Raw** URL for the playlist, not the GitHub `blob` page URL. The streams are provided by the original playlist sources and may stop working or be unavailable in some regions. Only watch streams you are authorized to access.
